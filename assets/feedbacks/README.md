# Prints de avaliações publicados

Somente publique prints autorizados pelos clientes. Antes de enviar, oculte nomes, números, telefones, rostos e outros dados pessoais sem consentimento.

Adicione aqui arquivos JPG, PNG ou WebP. Depois, coloque seus caminhos no arquivo `assets/feedbacks.json` do repositório. Exemplo:

```json
{
  "items": ["assets/feedbacks/avaliacao-01.webp"]
}
```

O GitHub autentica quem altera o repositório. Não há upload público nem painel de edição na página do pet shop.
